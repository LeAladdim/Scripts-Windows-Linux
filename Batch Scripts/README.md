    Bem Vindo ao Teste do SAK.bat, seu canivete suiço para usar o Git em Pcs sem necessidade de instalação ou logins!
  
A ideia é, além disso, facilitar a vida de quem prefere um pouco mais de comodidade ao automatizar e juntar vários processos em um só executável .bat (que pode ser utilizado diretamente a partir do terminal da maioria das IDEs).

1° Etapa

Baixe o GIT PORTABLE nesse link
https://github.com/git-for-windows/git/releases/download/v2.55.0.windows.4/PortableGit-2.55.0.4-64-bit.7z.exe

2° Etapa 

Crie no seu pendrive uma pasta nomeada Git

3° Etapa

Execute o Git Portable e escolha a pasta de destino Git no seu pendrive

4° Etapa 

Salve o SAK.bat e o .gitignore.txt na raiz do seu Pendrive, além de criar um arquivo chamado Token.txt

5° Etapa

Lembre-se de gerar um Token no Github de acesso vitalício e o ter sempre a mão dentro do arquivo token.txt (NÃO COMPARTILHE SEU TOKEN E DEIXE APENAS ELE NO ARQUIVO). Você vai precisar dele para clonar seu repositório

6° Etapa 

Execute no terminal da sua IDE de preferência que possua terminal integrado (como Intelijj) o executável a partir do caminho (Deve ficar algo como: D:\SAK.bat, a depender da letra do seu pendrive) e seguir o processo


Bom Proveito, agora você consegue clonar seus repositórios, editar, iniciar Repos, dar merge em Branchs e mais em qualquer pc sem login, mesmo que ele não tenha Git instalado ou precise de permissões especiais.
